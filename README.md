# 💰 Student Expense Tracker

A simple and responsive web application that helps students
track and manage their daily expenses.

## 🚀 Live Demo

Add your live website link here after deploying the project.

## 📌 About the Project

Student Expense Tracker is a frontend web application developed
using HTML, CSS and JavaScript.

The application allows users to add, edit, delete and filter
their daily expenses. Expense data is stored in the browser
using JavaScript LocalStorage.

## ✨ Features

- Add new expenses
- Edit existing expenses
- Delete expenses
- Expense categories
- Search expenses
- Filter expenses by category
- Automatic total expense calculation
- Total transaction count
- Average expense calculation
- LocalStorage data persistence
- Responsive design
- Mobile-friendly interface

## ▶️ How to Run

1. Download or clone this repository.

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Start adding your expenses.

## 💾 Data Storage

This project uses browser LocalStorage to save expense data.

No external database is required.
